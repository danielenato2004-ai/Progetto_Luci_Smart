# Progetto Luci Smart

Progetto basato su **STM32** per la gestione e risparmio intelligente di sistemi di illuminazione realizzato dal gruppo 2: Nato Daniele, Gangemi Igor e Brancati Fabrizio.

## 📋 Descrizione

Questo repository contiene il firmware e la configurazione per un microcontrollore STM32 dedicato al controllo di luci smart. Sono inoltre presenti il datasheeet dell'LDR utilizzato e il diagramma di flusso del progetto finale.
